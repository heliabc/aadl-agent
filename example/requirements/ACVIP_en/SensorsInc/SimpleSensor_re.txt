The system shall define a public AADL package named SimpleSensor. This package shall declare explicit import dependencies on three pre-existing external packages to support component definition: the DataDictionary package that hosts standardized shared data type specifications, the Infrastructure package that provides pre-modeled communication bus and power supply interface definitions, and the SEI package that contains domain-specific extended non-functional property definitions. The SimpleSensor package shall contain exactly one device component type designated SimpleSensor, and one corresponding concrete device implementation designated SimpleSensor.i. The SimpleSensor.i implementation shall not declare any internal subcomponents, representing a self-contained monolithic hardware device without internal modular decomposition, so no internal interconnection interfaces between subcomponents are required.

The SimpleSensor device type shall expose three formal external features as its interaction interface with external system elements. The first feature is an outbound data port named dataOut, configured to send data to connected external components. The second feature is a required bus access point named busOut, which declares the device’s need to connect to a specified communication bus for off-device data exchange. The third feature is a required bus access point named powerIn, which declares the device’s need to connect to a power supply bus to receive operating power. No additional input ports, output ports, bus access points, or subprogram access points shall be defined on the SimpleSensor device type.

The SimpleSensor device type shall define a declared flow source named sensorFlow, whose origin point is the dataOut output port. This flow specification represents the unidirectional data transmission path for sensor measurement data, starting from the device’s internal sensing and processing logic and terminating at the dataOut port for delivery to external components. No intermediate flow steps, flow sinks, or end-to-end flows crossing internal subcomponent boundaries shall be defined within the device, as the device contains no internal subcomponents to form multi-hop flow paths. All sampled sensor data generated by the device shall exit the component exclusively through this defined flow path.

The SimpleSensor.i device implementation shall be configured to use a periodic dispatch protocol to govern its operational execution cycle. The fixed dispatch period for the device shall be set to 50 milliseconds, such that the device completes one full cycle of sensor sampling, data processing, and output preparation at consistent 50 millisecond intervals. The end-to-end latency associated with the sensorFlow path, measured from the instant raw sensor measurement is captured by the device’s sensing element to the instant valid formatted data is available for transmission at the dataOut port, shall be bounded between a minimum of 3 milliseconds and a maximum of 5 milliseconds. The device shall conform to a total weight limit of 0.2 kilograms as defined by the SEI property set. The device shall enforce a maximum power budget of 4.0 watts on the powerIn access interface, such that the total power drawn by the device through the power supply connection shall not exceed 4.0 watts under any nominal operating condition.

All data transmitted via the dataOut port shall strictly conform to the SensorData data type defined in the imported DataDictionary package; no local custom data type definitions shall be declared within the SimpleSensor package. The communication bus accessed via the busOut required interface shall be the concrete 1553 bus implementation instance identified as Infrastructure::bus1553.i, which shall act as the physical communication medium carrying sensor data from the device to other connected system elements. The power supply bus accessed via the powerIn required interface shall be the generic power bus instance identified as Infrastructure::power.generic, which shall deliver regulated operating power to the device. All non-functional property assignments applied to the device implementation and its features shall reference properties from the imported SEI property set, with no locally defined property sets or custom property declarations contained within the SimpleSensor package.
