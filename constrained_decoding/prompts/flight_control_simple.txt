包名：FlightControl

----------------------------------------------------------------------
一、组件列表（按生成顺序排列）
----------------------------------------------------------------------

1. FlightControlBus，类型 bus，不需要实现，无 features（不要生成 features 节）
2. FlightProcessor，类型 processor，需要实现，无 features（不要生成 features 节）
3. FlightControlProcess，类型 process，需要实现，无 features（不要生成 features 节）
4. IMUSensor，类型 device，不需要实现，有 features
5. GPSReceiver，类型 device，不需要实现，有 features
6. ActuatorController，类型 device，不需要实现，有 features
7. GuidanceThread，类型 thread，不需要实现，有 features
8. NavigationThread，类型 thread，不需要实现，有 features
9. ControlThread，类型 thread，不需要实现，有 features
10. FlightControlSystem，类型 system，需要实现，有 features

注意：bus、processor、process 类型的组件没有 features，不要生成 features 节，直接 end 结束。需要实现的，一定要有实现。

----------------------------------------------------------------------
二、每个组件的 features 说明（仅描述数量和方向，具体端口名自己推断）
----------------------------------------------------------------------

FlightControlSystem：3个输入 port，1个输出 port
IMUSensor：2个输出 port
GPSReceiver：2个输出 port
ActuatorController：1个输入 port，1个输出 port
GuidanceThread：1个输入 port，1个输出 port
NavigationThread：2个输入 port，1个输出 port
ControlThread：1个输入 port，1个输出 port

所有端口数据类型均为 Base_Types::Float。
端口命名使用 snake_case，根据组件功能合理推断。

----------------------------------------------------------------------
三、每个组件实现的 subcomponents
----------------------------------------------------------------------

FlightControlSystem.impl 的子组件：
  - processor FlightProcessor
  - device IMUSensor
  - device GPSReceiver
  - device ActuatorController
  - bus FlightControlBus

FlightProcessor.impl 的子组件：
  - process FlightControlProcess

FlightControlProcess.impl 的子组件：
  - thread GuidanceThread
  - thread NavigationThread
  - thread ControlThread

----------------------------------------------------------------------
四、每个组件实现的 connections 说明
----------------------------------------------------------------------

数据流方向：
IMUSensor → NavigationThread → GuidanceThread → ControlThread → ActuatorController
GPSReceiver ↗

FlightControlSystem.impl 需要完整的跨层级连接路径。
FlightControlProcess.impl 只需要内部线程之间的连接。
FlightProcessor.impl 没有 connections（不要生成 connections 节）。

连接名根据语义自己命名。

----------------------------------------------------------------------
五、生成规则
----------------------------------------------------------------------

1. 按上面列出的顺序生成 10 个组件类型声明
2. 需要实现的组件，在组件类型后面生成 .impl 实现
3. 无 features 的组件，不要生成 features 节，直接 end
4. 无 connections 的实现，不要生成 connections 节
5. 子组件的类别关键字必须和类型一致
6. 生成到 end FlightControl; 就停止

----------------------------------------------------------------------
六、AADL 语法参考
----------------------------------------------------------------------

有 features 的组件类型：
  <类别> <组件名>
    features
      <端口名>: <方向> data port <数据类型>;
    end <组件名>;

无 features 的组件类型：
  <类别> <组件名>
    end <组件名>;

组件实现：
  <类别> <组件名>.impl
    subcomponents
      <子组件名>: <子类别> <子类型名>;
    connections
      <连接名>: <源组件>.<源端口> -> <目标组件>.<目标端口>;
    end <组件名>.impl;
